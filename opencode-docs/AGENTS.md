# HEP Tracking Table

Static SvelteKit site (`web-app/`) that renders one table from `data/hep-tracking.json`. The JSON is generated by a Python sync script that reads a public Google Sheet; a GitHub Action commits the refreshed JSON.

## Decisions

- **Source is the published TSV, not the xlsx export.** TSV is plain text, so sheet rich text (bold/italic/color) is not available. Formatting was judged decoration, not content. Consequence: no HTML in the JSON, no `{@html}` needed in the table.
- **pandas for parsing.** `pd.read_csv` cannot read this export (a cell holds a bare CR, C parser raises `Buffer overflow caught`). Rows are split manually, then loaded into a DataFrame.
- **Two header rows.** Row 0 is a merged banner; row 1 is the real header.
- **Merged cells → forward fill.** `Goal, Objective Code, Objective Desc, Subtitle, Action Code, Action Desc` are filled only on the first row of each group; they are `ffill`ed before flattening to records.
- **Empty cells are JSON `null`, not `NaN`.** `NaN` is invalid JSON and would reach the browser.
- **The transform is the notebook, unchanged.** No row filtering, no extra cleaning, no schema validation. Only trailing whitespace stripping on the 6 group columns, as in `py/data_transform.ipynb`.
- `data/hep-tracking.xlsx` and the zip/XML rich-text parser were dropped (unused by the web app, not viewable on GitHub).

## Conventions

- Python: stdlib where possible; pandas pinned in `py/requirements.txt`.
- CI: `actions/setup-python` with `cache: pip`; no duplicate installs.
